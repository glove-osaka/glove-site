お客様の相談の進み具合

提携・協業の申し込みの進み具合

この画面の使い方（お客様の相談）
  1. 新しい相談は、ホームページから自動で入ります。電話で受けた相談は「＋ 相談を登録する」から入れます。
  2. 行を押すと、1件の画面が開きます。上の「次にやること」の案内に沿って進めます。
  3. 担当者を選び、「分類（大・中・小）」を確かめます。大分類と中分類は、お客様がホームページで選んだ内容から自動で入ります。
  4. 取次ぎ先が決まったら「振り分け」から選びます。選んだあと「取次ぎ先に内容を送る」で、確認してから提携先へ送れます。
  5. 状態を変えると、お客様への進捗報告の文章が作られます。送るかどうかは、担当者が決めます。
受付お名前・ご関係分類振り分け進み具合注意担当・次にやること
この画面の使い方（取次ぎ）
  1. 取次ぎは、お客様の相談を提携先・自社・士業などへつないだ記録です。「お客様の相談」の画面の「振り分け」から作ります。
  2. 行を押すと、くわしい画面が開きます。「取次ぎ先に内容を送る」を押すと、送る内容を確かめてから送れます（勝手には送られません）。
  3. 見積もり・成約・完了など、進み具合が変わったら状態を直して保存します。
依頼日相談者取次ぎ先分類・内容送信状態金額
この画面の使い方（提携・協業の申し込み）
  1. 申し込みページから届いた申し込みが入ります。お客様の相談とは別に管理し、取次ぎ（振り分け）はしません。窓口（自社）だけで対応します。
  2. 行を押すと、申し込みの内容と「次にやること」が出ます。担当者を決め、面談の日を決めます。
  3. 面談のあと、確認する項目に印を付け、秘密保持契約書・業務提携契約書を送ります。
  4. 契約が済んだら「提携を始める」を押すと、提携先（会員）の一覧に移り、取次ぎ先として選べるようになります。

この画面の使い方（電子契約）
  1. 「契約書の種類」を選び、相手のお名前とメールアドレスを入れて「メールで送る」を押します。
  2. 先に内容を見てもらいたいときは「下書き（確認用）として送る」に印を付けます。相手は内容を見て「問題ありません」か「直してほしいところがあります」を返せます。
  3. 「問題なし」の返事が来たら、一覧の「この内容で本契約を送る」を押します。同じ契約書・同じリンクのまま、締結できる正式な契約書になります。
  4. 直してほしいと返事が来たら「直して出し直す」を押すと、前の内容が入った状態で作り直せます（前の下書きは自動で取り消しになります）。
  5. 相手が承認すると「締結済み」になり、PDFを保存できます。

契約書を送る

契約書の「甲」に載る名前です。契約書の種類を選ぶと、よく使う名義に自動で切り替わります。

追加した名義は、担当者も選べるようになります。最初からある3つは消せません。

管理画面の使い方

担当者のアカウントでは、次のことができます。

  1. ホーム：自分が登録した提携先と、送った登録フォームの一覧が見られます。
  2. 提携先を登録する：面談などでお会いした会社を登録します。登録したあとの修正・削除は、管理者が行います。
  3. 登録フォームを送る：会社に申し込みページの案内をメールで送ります。そこから申し込まれると、あなたが登録した提携先として記録されます。
  4. 電子契約：契約書を送る・下書きのお返事を確かめる・本契約にする・取り消す、ができます（自分が出したものだけ見えます）。
  5. パスワード変更：自分のパスワードを変えられます。担当者名は、ログインした人の名前で決まっています。

お客様の相談・提携先（会員）の名簿は、管理者だけが見られます。

はじめての方は、まず「今やること」を開き、上から順に片付けてください。

お客様の相談の流れ

新規→連絡済み→面談予定→対応中／取次ぎ中→完了

  1. ホームページから届いたら、まずお電話。状態を「連絡済み」にします。
  2. 担当者・分類を確かめ、面談や訪問の日を「次にやること」と「期日」に入れます。
  3. 振り分けで取次ぎ先を選び、「取次ぎ先に内容を送る」で確認してから送ります。
  4. 進み具合が変わったら、お客様に報告するかどうかを決めます。

提携・協業の申し込みの流れ（自社だけで対応）

新規申込→連絡済み→面談日調整中→面談予定→面談済み・確認中→契約書送付済み→提携開始

  1. 申し込みが届いたら、担当者を決めて面談の日を調整します。
  2. 面談のあと、確認する項目に印を付け、契約書を送ります。
  3. 契約が済んだら「提携を始める」。提携先（会員）になり、取次ぎ先として選べるようになります。

それぞれの画面

  • 今やること：急ぐものが上から並びます。
  • お客様の相談：ご相談の一覧と、1件ずつの対応。
  • 取次ぎ：提携先などへつないだ記録。
  • 提携・協業の申し込み：申し込みの対応（面談・確認・契約）。
  • 提携先（会員）：提携中の会社の一覧。分類で絞り込めます。
  • 電子契約：契約書を送る・一覧。
  • 担当者：担当者の名簿。
