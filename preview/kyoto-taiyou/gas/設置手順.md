# 事務所管理の保存先（Googleスプレッドシート）の設置手順

所要時間：約20分。先生の事務所用のGoogleアカウントで行います（メールはこのアカウントのGmailから送られます）。

## 1. スプレッドシートを作る
1. Googleドライブで「新規 → Googleスプレッドシート」を作り、名前を「京都太陽 事務所管理」にする
2. 上のメニュー「拡張機能 → Apps Script」を開く
3. 最初から入っている文字をすべて消し、`Code.gs` の中身をすべて貼り付けて保存する

## 2. 初回の準備
1. 上の関数の選択欄で `setup` を選び「実行」を押す
2. 権限の確認が出たら、事務所のアカウントを選んで「許可」する
3. スプレッドシートに「相談受付・顧客・対応・予定・日報・見積請求・入金・支払い・契約・設定・担当者」のシートができる
4. 「担当者」シートの合言葉の欄に、先生とMAさんの合言葉を入れる（ログインに使います）

## 3. 設定を登録する
Apps Scriptの左の歯車「プロジェクトの設定」→「スクリプト プロパティ」に次を追加する。

| プロパティ | 入れる値 |
|---|---|
| NOTIFY_TO | 新しい相談の通知先（例：contact@kyoto-taiyou.com） |
| OFFICE_NAME | 京都太陽行政書士事務所 |
| SITE_URL | サイトのアドレス（最後に / を付ける） |
| ANTHROPIC_API_KEY | AIを使う場合だけ。Claudeの開発者向けの鍵 |

## 4. 公開する
1. 右上「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」
2. 「次のユーザーとして実行」：自分、「アクセスできるユーザー」：全員
3. 「デプロイ」を押し、表示されたアドレス（https://script.google.com/macros/s/…/exec）を控える

## 5. サイトとつなぐ
- `kt-common.js` の1行目近くにある `KT_API = ''` の '' の中に、控えたアドレスを入れる
- これで、サイトの相談フォーム・管理画面・署名ページが、すべてこのスプレッドシートに保存されるようになります

## 注意
- 合言葉は「担当者」シートに書かれるため、スプレッドシートは他の人と共有しないでください
- 相談の添付資料は、ドライブの「相談の添付資料」フォルダに保存されます
- Gmailの送信には1日あたりの上限があります（個人のアカウントで約100通）
