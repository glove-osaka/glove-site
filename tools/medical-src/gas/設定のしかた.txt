医療介護総合支援会　電子契約＋フォーム受付　設定のしかた（所要 約15分）

このスクリプト1つで、支援会サイトの「電子契約」と「相談・会員登録の申込みフォームの受付」の両方を受けます。
受付は台帳の「受付」シートに入り、NOTIFY_TO に通知、申込者には受付番号つきの控えメールが届きます。
他のサイト（グローブ・家じまいなど）のフォームとは完全に別になります。
=====================================================

使うもの：支援会で使う Google アカウント（家じまいとは別のアカウント・別の台帳にします）

1. Apps Script を作る
   https://script.google.com/ →「新しいプロジェクト」→ 名前「医療介護総合支援会 電子契約」
   ・左の「プロジェクトの設定」→「appsscript.json をエディタで表示する」にチェック
   ・コード.gs の中身を全部消して、同梱の「コード.gs」を貼り付け
   ・appsscript.json に、同梱の「appsscript.json」を貼り付け
   ・「＋」→「HTML」で、名前を admin にして、同梱の「admin.html」を貼り付け
   ・保存

2. 準備を実行する
   上の関数の選択で「setup」を選び「実行」→ 権限の確認で「許可」
   → 台帳（スプレッドシート）と Drive のフォルダができます。
   「プロジェクトの設定」→「スクリプト プロパティ」に次ができていることを確認：
     SHEET_ID / FOLDER_ID … 自動
     ADMIN_EMAILS … 管理画面を開ける Google アカウント（カンマ区切りで追加可）
     NOTIFY_TO    … 締結の通知を受けるメールアドレス（例：ikshienkai@gmail.com）
     SIGN_URL     … https://glove-osaka.github.io/glove-site/medical/keiyaku/index.html
     COMPANY_SEAL … （任意）会社印の画像（透過PNG）を Drive に置いたときのファイルID

3. お客様用の公開（デプロイ1）
   「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
     次のユーザーとして実行：自分
     アクセスできるユーザー：全員
   → 出てきた URL（…/exec）を控える ＝ KEIYAKU_API_URL

4. 管理画面用の公開（デプロイ2）
   もう一度「新しいデプロイ」→ ウェブアプリ
     次のユーザーとして実行：自分
     アクセスできるユーザー：自分のみ
   → 出てきた URL の末尾に ?admin=1 を付けたもの ＝ KEIYAKU_ADMIN_URL

5. 2つの URL を Claude に伝える（サイトの keiyaku/config.js に入れて公開します）

6. 動作確認（サイトの「会員登録の申込み」から自分のメールで申し込み → そのまま電子契約の画面へ進むことも確認）
   管理画面で「秘密保持契約書」を自分あてに送り → メールのボタン → 認証コード → 記入・押印・承認
   → PDF がメールで届き、台帳とフォルダに記録されれば完了

コードを直したとき：「デプロイを管理」→ 各デプロイの鉛筆 →「新バージョン」で更新（URLは変わりません）

注意
・無料の Google アカウントのメール送信は1日100通までです。
・本人確認書類の写真は Drive のフォルダに入ります。フォルダは共有しないでください。
・管理画面は ADMIN_EMAILS のアカウント以外では開けません。
