この画面の使い方（案件管理）
  1. 赤い印の案件から対応します。新しい受付ほど上に出ます。
  2. 案件の「受付の内容を見る」を押して、内容を読みます。
  3. 読んだら「状態」を進め、「振分け先」「担当」「次の対応予定日」を入れて「保存」を押します。
  4. お客様に伝えることがあれば「お客様へ報告を作る」を押します。文面は自動で作られます。送るかどうかは自分で決めます（電話で伝えた・今回は送らない、も選べます）。
  5. いちばん上の種別（企業・事業者／働く方／利用者・ご本人／ご家族／提携・協業の申込み／要望・ご意見／会員登録）を押すと、その種別だけを管理できます。状態・振分け先・対応の種類は種別ごとに変わります。
  6. その下の数字のボタンを押すと、その状態の案件だけを表示します。

状態の並びは種別（企業・働く方・提携の申込みなど）ごとに変わります。いま選んでいる種別の状態：

この画面の使い方（会員・相談者の名簿）
  1. 上で「会員名簿」か「相談者・申込者」を選びます。
  2. 左の分類を押すと、その分類の人だけが表に出ます（数字は人数）。
  3. 「さがす」で名前・会社・メールから探せます。
  4. 「表計算ソフト用に保存」で、いま表に出ている名簿をファイルに保存できます。
  5. 相談者の行の「案件を見る」を押すと、案件管理のその案件へ移ります。

この画面の使い方（対応ログ）
  1. 管理画面でしたこと（案件の状態・メモ・報告・提携先への送付、契約書の送付・入金確認・退会、提携先や担当者の登録、ログイン）が、いつ・だれが・何をしたかで自動的に残ります。
  2. サイトからの受付、毎月の請求書の自動送付、相手が契約書を承認したことも残ります。
  3. 「操作した人」は、画面右上の「操作する人」で選んだ名前です。操作の前に、自分の名前を選んでください。
  4. 番号を押すと、その案件へ移ります。「表計算ソフト用に保存」で、いま出ている記録をファイルに保存できます。
  5. 記録は消したり書き換えたりできません（Googleの台帳「対応履歴」に保存されます）。

この画面の使い方（設定）
  1. 担当者：案件の「担当」で選べる名前を登録します。
  2. 提携先の登録：振分け先にする提携企業・専門家を、大分類・中分類・小分類・連絡先とあわせて登録します。案件では、分類を選ぶと当てはまる提携先だけが一覧に出ます。メールを登録した提携先には、案件の「提携先へ送る」で案件を送れます。登録済みの提携先は、一覧の「直す」「削除」で変えられます（その場で保存されます）。
  3. 新しい受付は、相談の内容から分類を自動で決め、当てはまる提携先がいれば振分け先に自動で入ります。
  4. 担当者は「担当者を保存する」を押すと反映されます。

この画面の使い方（電子契約）
  1. サイトの会員登録は、お客様が申し込むと自動で契約書が作られます。ここで送る必要はありません。
  2. 相手が承認すると「締結済み」になり、請求書つきの振込のご案内が自動で届きます（期限は承認日から7日。入会した月は無料）。
  3. 毎月1日の朝に、翌月分の請求書が自動で全員に届きます（期限は10日）。送った内容は登録メールにも届きます。
  4. 会員が退会するときは、その行の「退会（請求を止める）」を押します。翌月から請求書が止まります。
  5. 通帳などで入金を確かめたら、その行の「入金を確認した」を押します。会員登録完了のメールが自動で届きます。
  6. 相手がまだ承認していないときは「もう一度送る」で案内を送り直せます。
  7. 協賛会員（審査あり）や、個別の契約書は、下の「契約書を送る」から作って送ります。
